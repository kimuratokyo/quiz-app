# Flashcard Studio (3Dフラッシュカードアプリ)

React, TypeScript, Tailwind CSS, Framer Motion を用いて構築された、シングルページアプリケーション (SPA) の高機能フラッシュカードアプリです。
まるで本物の単語帳をめくっているような3Dフリップアニメーションと、直感的なスワイプ操作を提供します。

## 🌟 システム概要

- **完全なフロントエンドアプリ**: バックエンドサーバーやデータベースを必要とせず、すべての処理（状態管理、アニメーション、ローカルストレージへの保存）がクライアントサイドで完結します。
- **リッチなUI/UX**: `Framer Motion` による滑らかで確実なアニメーションと、グラスモーフィズムを取り入れた最新のUIデザインを採用しています。
- **永続化**: ブックマーク機能やアニメーション設定はブラウザの `localStorage` に保存され、次回アクセス時にも引き継がれます。

## 🔄 学習フロー

1. **トップ画面**: 
   - ジャンル（応用情報、統計検定など）と学習モード（全問演習 / ブックマーク演習）を選択します。
   - オプションとして「出題順のシャッフル」と「アニメーションのON/OFF」が切り替え可能です。
2. **学習（クイズ）画面**:
   - **表面**: 問題が表示されます。カードをタップ（またはSpaceキー）で裏返します。
   - **裏面**: 解答と詳細な解説が表示されます。
   - **操作**: 
     - **右スワイプ (または次へボタン/右矢印)**: 次の問題へ進みます。
     - **左スワイプ**: 現在の問題を「ブックマーク」に登録しつつ、次の問題へ進みます。
     - **戻るボタン**: 前の問題に戻ります。
3. **結果画面**:
   - 全ての問題を解き終えると表示され、トップ画面へ戻ることができます。

## 💻 動作環境・仕様

- **Node.js**: v16以上推奨
- **パッケージマネージャー**: npm
- **コア技術**: React 18, TypeScript, Vite
- **スタイリング**: Tailwind CSS (PostCSS)
- **アニメーション**: Framer Motion
- **対応デバイス**: PC（マウス・キーボード操作）、スマートフォン（タップ・スワイプ操作）対応のレスポンシブデザイン

## 🛠 問題を増やす（編集する）方法

クイズの問題データは、データベースではなくソースコード内に直接配列として定義されています。
問題を増やしたい場合は、`src/App.tsx` の上部にある `quizData` 配列に新しいデータを追加するだけです。

```typescript
// src/App.tsx の17行目付近
const quizData: Question[] = [
  { 
    id: '新しいID', // 必ず他と被らない一意のIDを指定してください
    genre: 'ジャンル名', // トップ画面で自動的にこのジャンルごとにグループ分けされます
    question: '問題文をここに書きます。', 
    answer: '解答をここに書きます。', 
    explanation: '詳しい解説をここに書きます。' 
  },
  // ... 既存の問題
];
```

追加・保存すると、Viteの機能によりブラウザが自動更新され、すぐに新しい問題が反映されます。

## 🚀 ローカルでの実行方法

手元のPCで開発・確認する場合は、以下のコマンドを実行します。

```bash
# 1. 必要なパッケージのインストール（初回のみ）
npm install

# 2. 開発サーバーの起動
npm run dev
```
ターミナルに表示される `http://localhost:5173/` にブラウザでアクセスしてください。

## 🌐 インターネットへの公開（デプロイ）

他の人もアクセスできるようにするには、アプリをビルドしてWebサーバーにデプロイする必要があります。

```bash
# 本番用ファイルの生成（ビルド）
npm run build
```

実行後、新しく `dist` というフォルダが作成されます。このフォルダの中身が「完成したWebサイトのデータ」です。
**Vercel**, **Netlify**, **GitHub Pages** などの無料ホスティングサービスに、この `dist` フォルダをアップロード（またはGitHub経由で連携）することで、簡単に世界中に公開することができます。

## 🏷 バージョン管理ルール

本アプリケーションは、機能の追加や修正を行うごとにバージョン番号を更新して管理します。
バージョン表記は `v1.0.0` のような3つの数字（セマンティックバージョニング）を使用します。

- **メジャー (vX.0.0)**: アプリ全体のデザイン刷新や、互換性がなくなるほどの大規模な仕様変更を行った場合。
- **マイナー (v1.X.0)**: 新しい機能（例：新しい学習モードの追加など）を追加した場合。
- **パッチ (v1.0.X)**: バグ修正や、UIの微調整、問題データ(`quizData`)のみの追加・修正を行った場合。

**バージョンの更新手順:**
変更をデプロイ（公開）する前に、`src/App.tsx` 内のタイトル画面最下部にあるバージョン表記（例: `<span>v1.0.1</span>`）の数字を手動で書き換えてください。
